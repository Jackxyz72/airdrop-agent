# airdrop-agent

Autonomous airdrop operator skill — one agent covers the whole airdrop cycle:
identities & HD wallets (EVM/Solana), Telegram/X/Discord socials, quest running,
testnet faucets/deploys, airdrop radar with scam scoring, daily autopilot, and a
policy engine with approval gates and a kill switch.

- Entry point: [`SKILL.md`](SKILL.md)
- Full documentation: [`docs/`](docs/) — capabilities, architecture, safety,
  quests, targets, sessions, Cloudflare, sybil, troubleshooting, and more.
